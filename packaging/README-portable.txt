Hikasa: compare folders and files.

hikasa      is the command line: run `hikasa --help` or `hikasa help`.
hikasa-gui  is the desktop application.

Keep both programs in one folder: `hikasa gui …` starts the hikasa-gui beside it, and looks on PATH otherwise.

A file named hikasa-portable.toml beside the programs (it may be empty) keeps all settings in that folder. The
Windows portable package comes with this file; delete it to use the normal settings folder instead.
