# Quick Compare

Actions ▸ **Quick Compare** in the [Folder Compare view](topic:view-folder-compare) lists the content result of each
selected file pair (at most 1,000; the rest is counted as "… and n more"), Binary or Rules-based. Each result is the one
[hikasa quick](topic:quick) gives for the pair. Select a line and press **Open** to open the pair in a Text Compare
view. The method is remembered.
