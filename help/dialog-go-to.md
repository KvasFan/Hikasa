# Go To (text views)

Search ▸ **Go To…** (Ctrl+G) in a Text Compare or Text Edit view moves the caret of the pane with the keyboard.

- Type a line number (`120`), a line and a column (`120:7`), or a column of the current line (`:7`). Numbers start at
  1 and count physical lines, as the line numbers show them.
- A line past the end goes to the last line; a column past a line's end goes to its end.
- A word that is not a position stays in the field with the reason under it.

See [The Text Compare view](topic:view-text-compare).
