# Text Compare Info

Session ▸ **Text Compare Info** (Ctrl+I; *Text Edit Info* in a Text Edit view) shows the figures of the view.

- Per file: its name, lines, encoding with its byte order mark, line endings (how many of each), format and why it was
  chosen, size on disk, whether it may be edited and whether it is modified.
- The comparison: rows by state and importance, sections, ignored rows, the alignment engine used, the times, and the
  warnings of the last comparison. While edits wait for the comparison the table says *provisional*.

**Copy** puts the table on the clipboard as text. See [The Text Compare view](topic:view-text-compare).
