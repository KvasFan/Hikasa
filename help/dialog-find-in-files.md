# Find in Files

Search ▸ **Find in Files…** (Shift+Ctrl+F) searches files and folders for a text, as `hikasa text find` does.

- **Find what**, with **Match case**, **Whole words** and **Regular expression**.
- **Look in**: one or more folders or files (**Add** another, **Browse…**); it starts with the folders of the active
  view's files.
- **File masks**: the names searched, as in the folder views' filters (`*.c;*.h;-obj\`); `*` searches every file.
- **Include subfolders**, **Include hidden items**, **Search inside archives** (an archive is searched as a folder),
  **Encoding** (detected, or one label for every file), **Convert with the format's converter**.
- **Advanced**: the most hits (100,000), hits per file (10,000) and the largest file searched (128 MiB).

**Find** checks the words and starts the search; the hits arrive in the [results panel](topic:panel-find-in-files)
at the bottom of the window. The choices are remembered for the next time.
