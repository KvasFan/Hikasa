# Layout (Hex Compare)

View ▸ **Layout…** of a [Hex Compare view](topic:view-hex-compare) sets how its rows look:

- **Bytes per line**: 1 to 256 (8, 16, 24, 32 and 64 with one click).
- **Group bytes by**: 1, 2, 4 or 8 bytes between spaces (with 1, an extra space after every 8 bytes).
- **Characters**: ASCII, Latin-1 or none.
- **Addresses**: shown or hidden, in hexadecimal or decimal.
- **Panes**: side by side or over-under.
- **Context rows of Differences**: the rows shown around each difference under *Show Differences* (0 to 64).
- **Use for new Hex Compare views**: the same choices become the defaults of the Hex Compare session type.

OK applies them to the view, keeping the first byte on screen in place. They belong to the view's session as its view
state: saving the session keeps them, and changing them does not make the session modified.
