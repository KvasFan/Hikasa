# Go To

Session views of type Table Compare: Search ▸ **Go To…** (Ctrl+G) moves the current cell.

- **Row**: a row number as the row numbers show it, on either side (the left side first). `12:B` names the row and
  the column at once.
- **Column**: a header name or the column letters of either side; empty keeps the current column. A hidden column is
  shown again.
- **Sheet**: the sheet pair, when there are several.

A row the display filter hides is not found: choose Show All first. See [The Table Compare
view](topic:view-table-compare).
