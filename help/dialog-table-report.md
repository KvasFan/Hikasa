# Table Compare Report

Session ▸ **Table Compare Report…** of a [Table Compare view](topic:view-table-compare) opens the
[report dialog](topic:dialog-report) of every view kind with the table's layouts (side by side, interleaved, summary,
XML, JSON), its rows (all, differences, same, none) and its options (row numbers, the cells of JSON), as `hikasa table
compare --report` writes them ([hikasa table compare](topic:table-compare)).

The choices of the earlier table dialog (HTML or plain text, the folder of relative paths) are read once and then
remembered as the report dialog's.
