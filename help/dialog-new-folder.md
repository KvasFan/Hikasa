# New Folder

Actions ▸ **New Folder…** (Ins) in the [Folder Compare view](topic:view-folder-compare) creates a folder in the current
row's folder: a folder row itself, the folder of a file row, else the base folders.

- **Name**: the new folder's name (a name with a separator is refused).
- **Create on**: the focused side when one is focused, else the sides used last; read-only sides are off.

The preview shows what is created; **Start** creates it. See [hikasa folder op](topic:folder-op) `mkdir --in`.
