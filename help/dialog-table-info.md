# Table Compare Info

Session ▸ **Table Compare Info** (Ctrl+I) shows the statistics of a [Table Compare view](topic:view-table-compare):

- **Sheets**: the sheet pairs, the sheets on one side only and the sheets with differences.
- **All sheets** and then each sheet: its state, the rows of each side, same rows, changed rows (important and
  unimportant), orphan rows of each side, differing cells, the paired and one-sided columns, the header differences
  and the rows with duplicate keys.

**Copy** places the table as text on the clipboard.
