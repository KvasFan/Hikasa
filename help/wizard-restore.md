# Restore Factory Defaults

Tools ▸ Restore Factory Defaults… deletes your settings files, so the built-in defaults apply again.

1. Choose the categories: Program Options, Theme, Toolbars/Shortcuts/Menus, Program State, File Formats, Session
   defaults. Named sessions and workspaces go only with "Delete all named sessions" and "Delete all workspaces";
   a locked session stays unless "Include locked sessions" is on.
2. The next step lists every file that will be deleted; nothing has happened yet.

Finish deletes them and the settings apply at once. `hikasa settings restore-defaults --category` does the same from
the command line. See [Export Settings](topic:wizard-export), [Import Settings](topic:wizard-import),
[hikasa settings](topic:settings) and [Contents](topic:index).
