# Export Settings

Tools ▸ Export Settings… saves settings to a `.hikasa-pkg` file you can keep or move to another machine.

1. Choose the categories: Program Options, Theme, Toolbars/Shortcuts/Menus, Program State, Sessions, File Formats,
   Workspaces, System Info. For sessions, formats and workspaces choose All or pick items with Some.
2. Choose the file: a full path (a relative one is refused, nothing is expanded). The default is
   `hikasa-settings-<date>.hikasa-pkg` in your home folder; an existing file is replaced after a question.

The result lists what was written. `hikasa settings export` does the same from the command line. See
[Import Settings](topic:wizard-import), [Restore Factory Defaults](topic:wizard-restore),
[hikasa settings](topic:settings) and [Contents](topic:index).
